## 1. Conventions

### 1.1 Headers

| Header | Required | Example | Notes |
|---|---|---|---|
| `Content-Type` | Yes (body requests) | `application/json` | Use `multipart/form-data` for uploads |
| `Authorization` | Protected routes | `Bearer <accessToken>` | JWT access token |
| `x-guest-id` | Guest routes | `9f1c...uuid` | Guest cart/checkout session id (UUID generated by client, stored in localStorage) |
| `Accept-Language` | Optional | `en` \| `ar` | Multi-language support (bonus) |

### 1.2 Access Levels

| Level | Meaning |
|---|---|
| **Public** | No token required |
| **Guest/Auth** | Works with a JWT **or** an `x-guest-id` header |
| **Auth** | Any logged-in user |
| **Customer** | Role = `customer` |
| **Seller** | Role = `seller` **and** `sellerStatus = approved` |
| **Admin** | Role = `admin` |

### 1.3 Standard Success Response

```json
{
  "status": "success",
  "message": "Products fetched successfully",
  "data": { },
  "pagination": {
    "page": 1,
    "limit": 10,
    "totalPages": 12,
    "totalResults": 117
  }
}
```

### 1.4 Standard Error Response

```json
{
  "status": "fail",
  "message": "Validation error",
  "errors": [
    { "field": "email", "message": "Email is required" }
  ]
}
```

### 1.5 Global Query Parameters (list endpoints)

| Param | Type | Example | Description |
|---|---|---|---|
| `page` | number | `?page=2` | Page number (default `1`) |
| `limit` | number | `?limit=20` | Items per page (default `10`, max `100`) |
| `sort` | string | `?sort=-createdAt,price` | Comma-separated; `-` = descending |
| `fields` | string | `?fields=name,price,images` | Field projection |
| `search` | string | `?search=laptop` | Keyword search |

### 23.2 HTTP Status Codes

| Code | Meaning | Used when |
|---|---|---|
| `200` | OK | Successful GET / PATCH / PUT |
| `201` | Created | Resource created |
| `204` | No Content | Successful DELETE |
| `400` | Bad Request | Validation error, out-of-stock, invalid coupon |
| `401` | Unauthorized | Missing/expired/invalid token |
| `403` | Forbidden | Wrong role, unverified email, blocked account |
| `404` | Not Found | Resource does not exist |
| `409` | Conflict | Duplicate email/phone/SKU/coupon code |
| `422` | Unprocessable Entity | Semantic validation failure |
| `429` | Too Many Requests | Rate limit exceeded |
| `500` | Server Error | Unhandled exception |
